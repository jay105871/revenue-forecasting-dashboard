# 📈 Revenue Forecasting Dashboard

## Overview
This project is a time series forecasting system that predicts future revenue using ARIMA modeling. It includes an interactive Streamlit dashboard for KPI tracking and visualization.

---

## Features
- Historical revenue analysis
- 12-month revenue forecasting
- ARIMA time series model
- KPI metrics (growth rate, average revenue)
- Interactive Streamlit dashboard

---

## Tech Stack
- Python
- Streamlit
- Pandas
- Statsmodels (ARIMA)
- Matplotlib

---

## How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
